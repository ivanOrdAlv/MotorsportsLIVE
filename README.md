# 🏁 MotorSportsLIVE

**MotorSportsLIVE** es una aplicación web interactiva dedicada al mundo del automovilismo, donde puedes explorar eventos, circuitos, pilotos y mucho más. Desarrollada con JavaScript, Supabase, Node.js y desplegada con Vercel, ofrece una experiencia dinámica para fans, editores y administradores.

## 🚀 Características

- 🔐 Registro e inicio de sesión de usuarios (autenticación con Supabase)
- 👤 Roles diferenciados: Administrador, Editor e Invitado
- 📅 Gestión de eventos, pilotos, circuitos y resultados
- 🛠️ Panel de administración completo para crear, editar y eliminar contenido
- 🌍 Integración con Google Maps para mostrar circuitos
- 🎥 Soporte para vídeos, imágenes e historial de resultados
- 💡 Sistema de control de sesión con LocalStorage

## 📡 API REST

Accede a la API pública que alimenta esta aplicación con datos sobre carreras, pilotos y más:

👉 **[MotorSportsLIVE API en GitHub](https://github.com/ivanOrdAlv/MotorSportsLIVE-API)**

Incluye endpoints para:
- `GET /circuitos`
- `GET /pilotos`
- `GET /eventos`
- `POST`, `PUT`, `DELETE` para administradores
